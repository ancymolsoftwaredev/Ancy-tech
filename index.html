// Featured build

A WhatsApp assistant for a
Dubai real-estate agency

Live demo · Node.js · n8n · Meta WhatsApp Cloud API

Every Bayut lead answered in seconds — in English or Arabic.

Property leads arrive at all hours, and a missed call usually means a lost tenant. I designed and built the whole platform: a bot that qualifies the customer, matches them to real units, scores the lead and hands it to the right salesperson.

  • Smart question flow per property type (apartment, villa, office, shop)
  • Reads the Bayut listing reference and skips questions it already knows
  • Scores leads HOT / WARM / COLD and assigns an agent automatically
  • Missed-call recovery and timed follow-ups orchestrated with n8n
  • Team dashboard: chats, roles & logins, audit log, owner accountability view
Bayut lead→WhatsApp bot→Qualify→Match units→Agent + n8n
