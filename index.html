UAA Rental Operating System —
AI automation for real estate

Live in production · Node.js · n8n · Meta WhatsApp Cloud API

Every Bayut, Dubizzle and website lead answered in seconds — in English or Arabic.

Property leads arrive at all hours, and a missed call usually means a lost tenant. For United Arab Agencies (74 units across 10 buildings) I designed and built the whole platform: an AI chatbot that qualifies the customer, matches them to real units, scores the lead and hands it to the right salesperson — with a CRM dashboard to track every enquiry.

  • Smart question flow per property type (apartment, villa, office, shop)
  • Reads the Bayut listing reference and skips questions it already knows
  • Scores leads HOT / WARM / COLD and assigns an agent automatically
  • Missed-call recovery and timed follow-ups orchestrated with n8n
  • Website enquiries from uaa.ae flow straight into the same CRM
  • Team dashboard: chats, roles & logins, audit log, owner accountability view
