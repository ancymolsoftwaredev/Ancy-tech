Ancy Mol KK — Portfolio
=======================

A single, self-contained page. No build step, no dependencies, no internet
required — everything (styles, scripts, logo, fonts) is inside index.html.

HOW TO VIEW
-----------
Just double-click index.html — it opens in any browser.

HOW TO PUT IT ONLINE (free options)
-----------------------------------
- GitHub Pages: create a repo, upload index.html, enable Pages.
- Netlify / Vercel / Cloudflare Pages: drag the folder into their dashboard.
- Any web host: upload index.html to your public_html / www folder.

FEATURES
--------
- Type into the hero terminal: help, projects, skills, open uaa, theme, clear
- Command palette: press Cmd/Ctrl + K
- Light / dark themes (sun icon, top-right)
- Live network background, animated "funnel" pipeline, count-up stats

EDITING
-------
Open index.html in any text editor. Content is plain HTML near the top of
<body>; colors are CSS variables in the :root blocks at the very top.
